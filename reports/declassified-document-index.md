# Declassified and Public Document Index

Checked: 2026-06-01

Purpose: give the compiler one chronological launch page for public,
declassified, or public-control documents. Use this page before working the
[selection worksheet](selection-worksheet.html), [research request packet](research-request-packet.html),
or [source-note audit](source-note-style-audit.html).

Spreadsheet export: [declassified document index CSV](declassified-document-index.csv).

## Status Key

- Readable public copy: the document or public text can be read now.
- Public control PDF: an official online file packet exists, but may contain
  withdrawals or image-only pages.
- Public locator: the public record identifies the target but is not enough for
  final selection.
- Fallback/source anchor: useful for chronology, context, or public citation,
  but should be replaced by internal records when possible.

## Compiler Use

1. Start with the chronological index and open the public/control copy where one
   exists.
2. For any candidate marked partial, locator, fallback, or source anchor, use
   the linked request batch before treating the item as selected.
3. Draft source notes from repository/series/control facts, not from the URLs
   on this page. Use the [source-note audit](source-note-style-audit.html) for
   the required FRUS-style order.
4. Record sent requests and responses in the [request tracking ledger](request-tracking-ledger.html).
