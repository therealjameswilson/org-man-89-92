# Request Send Sheet

Checked: 2026-06-02

Purpose: compact send-ready companion to the [research request
packet](research-request-packet.html). Use this page when the compiler is
actually submitting or logging requests: it gives the subject line, route,
control links to include, and the same-pass update that keeps the public site
consistent.

Spreadsheet export: [request send sheet CSV](request-send-sheet.csv).

Route anchors were checked on June 2, 2026. Use the [Bush Library contact
page](https://www.bush41library.gov/about-us/contact) for Textual Archives and
reference questions. Use the [NARA MDR contacts page](https://www.archives.gov/isoo/contact/mdr-contact.html)
for Presidential Libraries MDR, CIA, State, and other agency declassification
routes. The route page is the authority if an address, form, or intake method
changes.

## Same-Pass Closeout

After each request is sent, update these pages before moving to the next
batch:

1. Enter sent date, route, and any acknowledgement or tracking number in the
   [request tracking ledger](request-tracking-ledger.html).
2. If the request changes evidence status, update the [source note
   worklist](source-note-worklist.html) and [selection worksheet](selection-worksheet.html).
3. If the response affects terminal date, fallback use, chapter architecture,
   or document-slot priority, update the [compiler decision log](compiler-decision-log.html).
4. Before any candidate becomes selected or source-note-ready, run the
   [promotion gate checklist](promotion-gate-checklist.html).
