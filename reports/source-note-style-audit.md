# Source Note Style Audit

Checked: 2026-05-25

Reference volume: *Foreign Relations of the United States, 1989-1992, Volume
XXXI, START I, 1989-1991*.

## Finding

The project source notes should be rewritten in FRUS document-note style before
any candidate is promoted to selected-document status. The existing reports are
mostly discovery notes, so NAIDs, web links, and "locator" language are useful
internally but should not be treated as final source notes.

Published FRUS source notes follow a compact order:

1. `Source:`
2. Repository or originating agency.
3. Record group, office, collection, series, file unit, OA/ID, box, folder, or
   document number.
4. Classification and handling markings.
5. Short provenance notes: initials, drafting/clearance, routing, stamped
   notations, presidential marginalia, meeting location, attachments, omitted
   portions, or cross-references.

The source note should not lead with a URL, NAID, PDF filename, or explanatory
assessment. Those belong in compiler notes, pull matrices, or source lists.

## FRUS-Style Templates

Use these patterns when drafting final source notes.

### Bush Library NSR/NSD/H-Files

`Source: George H.W. Bush Library, Bush Presidential Records, National Security Council, H-Files, [NSR Files/NSD Files/NSC Meetings Files], OA/ID [number], [folder title]. [Classification; handling]. [Routing, annotations, or meeting-location note.]`

### Department of State Central Foreign Policy File

`Source: Department of State, Central Foreign Policy File, [Electronic Telegrams/STARS/P Reels], [document number]. [Classification; handling; precedence]. [Drafting, clearance, or cross-reference note.]`

### Department of State Lot Files

`Source: Department of State, [office or Executive Secretariat], [records series], Lot [number], [collection title], [folder title]. [Classification; handling]. [Drafted by/cleared by/meeting location/cross-reference note.]`

### White House or NSC Staff Files

`Source: George H.W. Bush Library, Bush Presidential Records, [White House office or NSC staff member files], [series], OA/ID [number], [folder title]. [Classification; handling]. [Sent for action/information, sent through, stamped notation, or presidential annotation.]`

### CIA/PDB Process Records

`Source: Central Intelligence Agency, [office/record series to be verified], [PDB Staff/CPAS file title], [date or control number]. [Classification; handling]. [Briefing, distribution-control, tasking, or presidential-feedback note.]`

If the final selected item is not an intelligence text but a control record,
say so in the document title and keep the note factual. For example: "Attached
but not printed" and "not found" statements should appear only when the file
actually supports them.

### Public or Printed Fallback Sources

`Source: Department of State, [publication title], [issue/date], pp. [pages]. No classification marking. [Editorial note explaining why no archival copy was located, if needed.]`

Use this only as a fallback. The preferred FRUS source note should cite the
archival control copy, not a public reprint, whenever the control copy can be
located.

## Editorial Rules For This Project

- Keep NAIDs and URLs in pull matrices, not in finished source notes, unless
  the online catalog is the only available locator in a working note.
- Use "No classification marking" only when the document itself has no marking.
  Do not infer it from a public reprint.
- Include handling markings after classification: `Secret; Nodis`, `Secret;
  Exdis`, `Top Secret; Sensitive; Eyes Only`, and similar forms.
- Add drafting and clearance details when visible, especially for memoranda of
  conversation and State papers.
- Add presidential annotations and stamped notations when visible.
- For meetings, include location when known from the record.
- For attachments, use "Attached but not printed" only when the attachment is
  present or clearly identified in the source document.
- For missing records, use a separate editorial footnote, not the source note,
  unless FRUS style in the target chapter calls for a short "not found" sentence.
