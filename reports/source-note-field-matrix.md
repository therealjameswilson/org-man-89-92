# Source Note Field Matrix

Checked: 2026-06-02

Purpose: translate response-intake facts into FRUS-style source notes by
source pool. Use this after filling the [response intake
sheet](response-intake-sheet.html) and before closing a row in the [source
note worklist](source-note-worklist.html).

Spreadsheet export: [source note field matrix CSV](source-note-field-matrix.csv).

## Core Rule

Final source notes should begin with repository or originating agency, not a
URL, NAID, PDF filename, or catalog assessment. Keep public links, catalog
records, and source evaluation in compiler notes. Put only proved archival,
publication, classification, and provenance facts in the source note.

## Closeout Test

Before marking a source-note row ready, confirm:

1. The source pool above matches the actual record, not just the topic.
2. Required fields are proved by the response or document face.
3. Classification and handling markings come from the record, not inference.
4. Any public URL or catalog record is only a locator unless fallback is
   documented and accepted.
5. The [candidate closeout board](candidate-closeout-board.html), [selection
   worksheet](selection-worksheet.html), and [promotion gate
   checklist](promotion-gate-checklist.html) agree.
