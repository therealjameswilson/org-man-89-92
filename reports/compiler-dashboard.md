## Do Not Do Yet

| Temptation | Better move |
| --- | --- |
| Mark public PDFs as final selected documents because they are reachable. | Run the [promotion gate checklist](promotion-gate-checklist.html) and capture source-note fields first. |
| Treat FAS directive indexes, CIA histories, Public Papers, statutes, Dispatch, Current Policy, or *State* magazine as archival control copies. | Use them as locators, public fallback, or editorial support until archival records are found or ruled out. |
| Freeze the intelligence chapter before request results arrive. | Keep the chapter architecture, but reserve final document slots until PDB, covert-action, and intelligence-budget records clear the gate. |
| Use Daily Diary/Daily Backup as substantive evidence. | Use it for time, place, participants, call status, and backup-material existence; pair it with memcons, telcons, NSC records, PDB process files, or WHPO captions. |
| Add case studies because the policy is historically important. | Include only one or two case studies, and only if they show organization, management, budget, staffing, authority, oversight, or implementation machinery. |
