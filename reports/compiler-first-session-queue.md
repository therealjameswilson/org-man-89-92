# Compiler First-Session Queue

Checked: 2026-06-02

Purpose: run one productive compiler session without hunting through the whole
site. Use this queue when the goal is to send or log the first requests, capture
tracking facts, and leave every linked workflow page consistent.

Spreadsheet export: [compiler first-session queue CSV](compiler-first-session-queue.csv).

Core rule: do not change selection status during the sending session. Send or
log the request, record the route and date in the [request tracking
ledger](request-tracking-ledger.html), and wait for response evidence before
using the [promotion gate checklist](promotion-gate-checklist.html).

## If There Is Only One Hour

Do Order 0, then Order 1, then Order 2. That sends or logs the strongest
intelligence-chapter evidence: covert-action procedure, congressional
notification, and intelligence budget/community management.

## If A Response Arrives Mid-Session

1. [Response triage sheet](response-triage-sheet.html)
