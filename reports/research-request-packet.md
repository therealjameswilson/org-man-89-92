# Research Request Packet

Checked: 2026-06-01

Purpose: request-ready language for the records that would most improve final
selection for *FRUS, 1989-1992, Volume II, Organization and Management of
Foreign Policy*. This page is intentionally operational: copy the relevant
request, keep the identifiers, and attach the public PDF or file-unit link when
submitting.

After sending a request, record status and responses in the
[request tracking ledger](request-tracking-ledger.html).
For send order and the pages to update after each response, use the
[compiler action board](compiler-action-board.html). For a compact
subject-line and route sheet, use the [request send
sheet](request-send-sheet.html). For incomplete-response wording, use the
[follow-up request sheet](follow-up-request-sheet.html).

Subject: MDR request - NSC/DC 151, Definition of Covert Action, July 5, 1990

```text
NAID: 352356448

conclusions, agenda tabs, draft statutory language, draft report language,

records documenting consultations with the Senate Select Committee on
Intelligence and House Permanent Select Committee on Intelligence.
```

Public controls: [file unit](https://www.bush41library.gov/digital-research-room/finding-aid/records-national-security-council-george-h-w-bush-administration?naid=352356448) and [public PDF](https://s3.amazonaws.com/NARAprodstorage/lz/presidential-libraries/bush/gb-nsc/H-Files/NSC-DC_Mtgs_312294079/41-bpr-nsc-hfiles-dc_mtgs-151-90015-009.pdf).

and location, participant list, whether summary/minutes are present, attachment
tabs, withdrawal-sheet exemptions, and any interagency or congressional

## Batch E: PDB Process and Daily Diary Corroboration

### E1. Bush PDB Process Records

Subject: Reference/MDR request - President Bush PDB process and control records, 1989-1992

Request:

```text
I request assistance locating releasable primary records documenting President
George H.W. Bush's Presidential Daily Brief process and control system,
1989-1992.

Please search or advise on PDB Staff and Office of Current Production and
Analytic Support records, including briefer notes, daily debriefs, control
sheets, tasking logs, distribution instructions, supplemental raw-reporting
covers, "Signs of the Times" material, handwritten presidential feedback, and
matching NSC morning-meeting records.

Public CIA histories identify the Bush PDB process as an interactive daily
briefing model with working-level CIA briefers, restricted distribution, and
follow-up tasking. The selected FRUS document should be a primary process or
control record where possible, not the later published CIA histories.
```

Public anchors: [*First Callers*](https://www.cia.gov/resources/csi/static/First-Callers-President-Brief.pdf), [*Getting to Know the President*](https://www.cia.gov/resources/csi/static/242fbcb4c50958e6d49fa7a3c2718a05/Getting-to-Know-the-President-Fourth-Edition-2021-web.pdf), and [Model Consumer article](https://www.cia.gov/resources/csi/static/Remembering-George-HW-Bush.pdf).

## Tracking Fields

Use this table for every request response so source notes can be closed without
re-reading the whole exchange. Classify the response first with the [response
triage sheet](response-triage-sheet.html), then use the [response intake
sheet](response-intake-sheet.html) for the full field-by-field capture.

| Field | Capture |
| --- | --- |
| Repository / agency | Exact repository and office responding. |
| Collection / record group | Bush Presidential Records, State lot file, CIA office, OMB file, etc. |
| Series | H-Files, NSC Meetings Files, NSC/DC Meetings, NSD Files, NSR Files, Daily Diary/Backup, lot-file series, or other exact series. |
| File unit / folder | Exact folder title and any box, OA/ID, local ID, or NAID. |
| Document | Date, title, drafter/originator, recipient, meeting time/place, and attachments. |
| Classification | Classification and handling markings exactly as visible. |
| Release status | Fully open, partially open, withdrawn, referred, denied, pending MDR, or not located. |
| FRUS action | Select, source-note support only, editorial note only, locator only, or drop. |
| Next step | MDR, appeal, agency referral follow-up, scan request, on-site review, or no action. |
